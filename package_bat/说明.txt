RenpyDocFinder 脚本目录（所有 .bat 只在这里维护）
================================================

名称
  exe 文件名 / 进程名 : RenpyDocFinder.exe
  窗口标题             : Renpy文档查询
  任务管理器显示名      : Renpy文档查询（exe 版本信息里的 FileDescription，打包时写入）

请先运行一次 删除多余bat.bat，清掉根目录与旧 package\ 里的转发脚本，
以及被合并掉的旧脚本；之后这里只保留下面这几个：

打包
  打包-正确图标文件夹版.bat   推荐：exe 图标=assets/ico/window-icon.*，输出 dist\win-unpacked\RenpyDocFinder.exe
  打包-安装程序.bat           输出 dist\RenpyDocFinder-Setup.exe（NSIS）
  打包-单文件便携exe.bat      输出 dist\RenpyDocFinder-Portable.exe
  打包-免下载文件夹版.bat     不走 electron-builder（最稳；图标与任务管理器名称为 Electron 默认）
  打包-Python文件夹版.bat     pywebview + PyInstaller onedir，输出 dist-py\RenpyDocFinder

检查与清理
  检查.bat                    图标可读性/尺寸 + build-res 状态 + 所有已构建 exe 的构建时间与
                              Windows 显示名（可确认任务管理器会显示什么）
  清理与关闭.bat              结束所有实例并删除 dist\ dist-py\ build-py\ 旧产物

维护
  更新文档.bat                拉取 Gitee 中文 + 官网英文 + 引用图片，然后重建索引
  重建索引.bat                node build/build.mjs
  复制文档图片.bat            把文档图片汇集到 assets/docimg（离线/打包用）
  生成图标PNG.bat             由 assets/ico/window-icon.gif 生成 256x256 PNG

调试
  调试.bat                    菜单：1 源码模式（直接看主进程报错） 2 运行打包产物并抓日志

常见问题
  1. 打包后任务管理器里还有旧名字的条目：那是旧 exe 还在运行或仍留在 dist 里。
     先跑 清理与关闭.bat，再重新打包，只启动打包脚本打印出来的那个 exe。
  2. 任务栏固定过的图标名字不会自动更新：右键取消固定，再重新固定新 exe。
  3. EBUSY / resource busy：打包前有实例在运行，脚本会自动结束进程并重试；
     若 dist\win-unpacked 仍被占用，产物会落到 dist\build-<随机数>，注意看 BUILD RESULT。
